# Salary Negotiation Skill

This directory vendors the Codex-compatible `谈薪skill_easy` variant from
[Ssupercoder/Salary-Negotiation-Skill](https://github.com/Ssupercoder/Salary-Negotiation-Skill).

- Source path: `谈薪skill_easy/`
- Source ref: `2688ef8e4931ab3c069593967ceeed1f79186b3e`
- Installed name: `salary-negotiation-skill`

The upstream repository also contains a full Python service and an OpenClaw
variant. This bundle includes the standalone Agent Skill variant so it can be
discovered by Codex, Cursor, Claude Code, and other tools supported by this
repository's `install.sh` script.
