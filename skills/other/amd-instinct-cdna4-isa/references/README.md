# CDNA4 ISA reference source

This directory intentionally does not contain AMD's PDF. The source document
is public but includes an AMD Specification Agreement that restricts copying
and redistribution.

Official URL:

<https://www.amd.com/content/dam/amd/en/documents/instinct-tech-docs/instruction-set-architectures/amd-instinct-cdna4-instruction-set-architecture.pdf>

Use `../download-cdna4-isa.sh` to fetch a local copy after accepting the
document's terms. The downloaded file is ignored by Git and should not be
committed or shared from this repository.
